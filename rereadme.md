# Re-README

> A second look at the nanochat project.

## TL;DR

nanochat lets you train and talk to your own ChatGPT clone from scratch — tokenizer, pretraining, finetuning, eval, inference, and a web UI — all for about $100 on a single 8xH100 node.

## How It Works

1. **Tokenizer** — A custom BPE tokenizer built in Rust (`rustbpe/`) and wrapped for Python via PyO3.
2. **Pretraining** — Train a base GPT model on raw text using `scripts/base_train.py`.
3. **Midtraining** — Continue training with curated data via `scripts/mid_train.py`.
4. **SFT** — Supervised fine-tuning to make the model conversational (`scripts/chat_sft.py`).
5. **RL** — Optional reinforcement learning for math tasks (`scripts/chat_rl.py`).
6. **Serving** — Chat with your model through a web UI (`scripts/chat_web.py`) or CLI (`scripts/chat_cli.py`).

## Cost Tiers

| Tier   | Depth | Params | Cost  | Train Time |
|--------|-------|--------|-------|------------|
| d20    | 20    | ~760M  | ~$100 | ~4 hours   |
| d26    | 26    | ~1.2B  | ~$300 | ~12 hours  |
| d32    | 32    | ~1.9B  | ~$800 | ~33 hours  |

## Eval Tasks

- **ARC** — Multiple-choice science questions
- **GSM8K** — Grade school math
- **HumanEval** — Simple Python coding
- **MMLU** — Broad multiple-choice knowledge
- **SpellingBee** — Letter counting and spelling
- **CORE** — Base model quality score (from the DCLM paper)
