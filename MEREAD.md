## What is nanochat?

nanochat is a full-stack, minimal ChatGPT clone — tokenization, pretraining, finetuning, evaluation, inference, and web serving — all in one clean codebase. Designed to run on a single 8xH100 node for under $100.

## Key Entry Points

- `speedrun.sh` — Train the ~$100 nanochat d20
- `run1000.sh` — Train the ~$800 nanochat d32
- `scripts/chat_web.py` — Serve the ChatGPT-like web UI
- `scripts/chat_cli.py` — Talk to nanochat over CLI
